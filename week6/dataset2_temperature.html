1 — Data Source

This dataset contains average monthly temperatures (°F) for six major U.S. cities. The figures are based on NOAA 1991–2020 Climate Normals. The data was compiled into a wide-format CSV where each month is a separate column.

Source: NOAA Climate Normals

The dataset is untidy because the month columns (Jan, Feb, …) are values of a variable (month), not variable names.

3 — Transformation Steps

Code 
# Define month order for proper sorting
month_levels <- c("Jan","Feb","Mar","Apr","May","Jun",
                  "Jul","Aug","Sep","Oct","Nov","Dec")

tidy_temp <- raw_temp |>
  # Step 1: Reshape from wide to long format
  pivot_longer(
    cols      = -City,
    names_to  = "month",
    values_to = "avg_temp_f"
  ) |>
  # Step 2: Rename columns to lowercase snake_case
  rename(city = City) |>
  # Step 3: Convert month to an ordered factor for correct plotting order
  mutate(month = factor(month, levels = month_levels, ordered = TRUE)) |>
  # Step 4: Add a month number column for convenience
  mutate(month_num = as.integer(month)) |>
  # Step 5: Remove any rows with missing values
  drop_na(avg_temp_f) |>
  # Step 6: Sort by city and month
  arrange(city, month_num)

4 — Analysis

Goal: Compare seasonal temperature patterns across U.S. cities.

Summary Table

Code 
temp_summary <- tidy_temp |>
  group_by(city) |>
  summarise(
    min_temp  = min(avg_temp_f),
    max_temp  = max(avg_temp_f),
    mean_temp = round(mean(avg_temp_f), 1),
    range     = max_temp - min_temp,
    .groups   = "drop"
  ) |>
  arrange(desc(range))

5 — Conclusions

The analysis reveals distinct seasonal patterns across the six cities.

Phoenix has the highest summer peak at 95 °F and the widest temperature range (41 °F), reflecting its desert climate.

Los Angeles has the most stable temperatures year-round, with a range of only 18 °F, thanks to its coastal Mediterranean climate.

Chicago experiences the most extreme winters (26 °F in January) among the cities, while Houston stays relatively warm even in winter.

Seattle shows the smallest seasonal swing among the northern cities, with mild year-round temperatures due to its Pacific maritime influence.

These patterns are consistent with each city’s geographic and climatic profile.
