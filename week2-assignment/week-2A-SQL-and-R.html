Approach

I will collect a small movie-ratings dataset by selecting six recent popular movies and asking at least five people to rate the movies they’ve seen on a 1–5 scale. I will store the results in a PostgreSQL database, using a simple schema (3 tables: users, movies, ratings with primary keys and foreign keys) and SQL scripts to create/populate the tables. Then I will load the ratings into R as a dataframe (either by querying the database from R or exporting to CSV first) and produce basic summaries such as average ratings by movie and counts of ratings per user/movie.

The main data challenge I anticipate is missing ratings, since not everyone will have seen every movie. I will handle this explicitly, for example, represent missing ratings as NULL in SQL, and decide whether to exclude missing values from averages or impute a reasonable placeholder depending on the metric.

Create tables

CREATE TABLE people (
  person_id SERIAL PRIMARY KEY,
  name TEXT NOT NULL UNIQUE
);

CREATE TABLE movies (
  movie_id SERIAL PRIMARY KEY,
  title TEXT NOT NULL UNIQUE,
  release_year INT NOT NULL
);

CREATE TABLE ratings (
  rating_id SERIAL PRIMARY KEY,
  person_id INT NOT NULL REFERENCES people(person_id),
  movie_id  INT NOT NULL REFERENCES movies(movie_id),
  rating INT NULL CHECK (rating BETWEEN 1 AND 5),
  UNIQUE (person_id, movie_id)
);

Quick SQL check

SELECT
  m.title,
  COUNT(r.rating) AS n_ratings,            -- counts non-NULL ratings
  ROUND(AVG(r.rating)::numeric, 2) AS avg_rating
FROM movies m
LEFT JOIN ratings r ON r.movie_id = m.movie_id
GROUP BY m.title
ORDER BY avg_rating DESC NULLS LAST;

  r.rating

Handle missing data + analysis

Missing-data strategy:
- In SQL we stored “not seen / not rated” as NULL
- In R, those become NA
- For averages, we ignore NA using na.rm = TRUE
- Report how many people rated each movie so averages aren’t misleading

Movie summary table

movie_summary <- df |>
  group_by(title, release_year) |>
  summarise(
    n_possible = n(),                 # total people rows per movie (should be 5 here)
    n_rated = sum(!is.na(rating)),    # how many actually rated
    avg_rating = mean(rating, na.rm = TRUE),
    .groups = "drop"
  ) |>
  arrange(desc(avg_rating))
