3a-global-baseline-estimate

Introduction

I use the survey data (movie-ratings) to build a simple recommender using the Global Baseline Estimate method. I’ll compute three key components:
1. the global mean rating across all observed ratings,
2. each user’s bias (how a user’s average rating differs from the global mean),
3. each movie’s bias (how a movie’s average rating differs from the global mean).
Using the spreadsheet’s algorithm, I will predict an unseen rating with predicted(u, m) = global_mean + user_bias(u) + movie_bias(m).

Finally, for each user, I will generate predictions for the movies they haven’t rated and recommend the movie(s) with the highest predicted score.

Missing data strategy

  • Missing ratings are represented as NA.
  • When computing averages, we exclude NA values so they do not distort the mean.
  • Predictions are generated only for movies a user has not rated (rating is NA).
ratings_long %>% summarise(
  total_rows = n(),
  missing_ratings = sum(is.na(rating)),
  observed_ratings = sum(!is.na(rating))
)

Global Baseline Estimate components

1) Global mean rating

This is the average of all observed ratings across all users and movies.

global_mean <- ratings_long %>%
  summarise(mu = mean(rating, na.rm = TRUE)) %>%
  pull(mu)

global_mean
[1] 4.291667

2) User bias

A user bias measures how a user rates compared to the global mean:

user_bias <- ratings_long %>%
  group_by(user) %>%
  summarise(user_avg = mean(rating, na.rm = TRUE), n_ratings = sum(!is.na(rating)), .groups = "drop") %>%
  mutate(b_user = user_avg - global_mean) %>%
  arrange(desc(b_user))

Predict missing ratings and recommend movies

The Global Baseline Estimate prediction is:

predictions <- ratings_long %>%
  left_join(user_bias %>% select(user, b_user), by = "user") %>%
  left_join(movie_bias %>% select(movie, b_movie), by = "movie") %>%
  mutate(pred_rating = global_mean + b_user + b_movie)

Conclusions

Using the Global Baseline Estimate method, I generated movie recommendations by combining the global average rating with a user bias and a movie bias. This provides a simple baseline recommender that works well with survey data, and it handles missing ratings naturally by predicting only for unseen movies.
